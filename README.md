# someone2639's Ultimate Gadget Game of Martial Arts!

In this 2-player game, fight to the... Life?! You're just a humble cube on a humble blockout stage, with a mallet that can fix things! Fix up your opponent to win! Or, fix up the stage enough times and unleash a devastating attack! Watch out though, you're vulnerable when attacking the stage! If you can hit your opponent enough times to make them conscious of the concept of losing, you win!

## Controls

A - Jump

B - Attack an Opponent

Z while in midair - Attack the Stage


## Building

Depends on libdragon unstable (`libdragon-unstable-git` and `libdragon-tools-unstable-git` on AUR)

Built on Zig 0.15.2 (If you're reading this and 0.16 is out, I still have no clue if it works)

run `make` to build the game
